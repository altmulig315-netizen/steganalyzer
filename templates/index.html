Identify & structure

1Encoded LayerDetects when the dropped file is itself binary/hex/base64 text hiding another file; decodes one layer and, if the result is an image, re-feeds it through every module below so OCR reads the flag. Non-image payloads (zip/pdf) get a download link.
🔧Corrupt-header repairWhen a file won’t render as an image, detects a known type whose magic bytes are damaged but whose body survives — JPEG (JFIF/Exif), PNG (IHDR/IDAT/IEND), GIF, ZIP (central dir), PDF (endobj/xref) — shows the header hex (current vs expected) and offers a one-click repair that rewrites the signature and re-runs every module on the fixed file. Any other unloadable file now degrades gracefully instead of crashing.
2File InformationMagic bytes, dimensions, MIME, unique colours, alpha, bit depth.
3Metadata / EXIFEXIF/JFIF markers, PNG tEXt/iTXt/zTXt chunks, embedded software hints.
4File StructurePNG chunk table (with CRC) or JPEG marker table.
5Embedded File ScanFinds the primary payload boundary; loudly flags files appended after the image; gives a dd/binwalk extract command.
7Hex DumpHeader (512 B) + tail (256 B) in hex and ASCII.
